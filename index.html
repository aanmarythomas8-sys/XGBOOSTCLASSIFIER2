Equivalent Python Code

Copy & execute this scikit-learn / xgboost script in your local environment

xgboost_pipeline.py 
import pandas as pd
import numpy as np
from xgboost import XGBClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score, confusion_matrix

# 1. Load Dataset
df = pd.read_csv('data.csv')
X = df.drop(columns=['diagnosis'])
y = df['diagnosis']

# 2. Train-Test Split (80/20 Stratified)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42, stratify=y
)

# 3. Instantiate XGBoost Classifier
model = XGBClassifier(
    n_estimators=30,
    learning_rate=0.10,
    max_depth=3,
    subsample=0.80,
    colsample_bytree=0.80,
    reg_alpha=0.0,
    random_state=42,
    eval_metric='logloss'
)

# 4. Train Model
model.fit(X_train, y_train)

# 5. Model Evaluation
y_pred = model.predict(X_test)
y_proba = model.predict_proba(X_test)[:, 1]

print("--- MODEL METRICS ---")
print(f"Accuracy:  {accuracy_score(y_test, y_pred):.4f}")
print(f"Precision: {precision_score(y_test, y_pred):.4f}")
print(f"Recall:    {recall_score(y_test, y_pred):.4f}")
print(f"F1 Score:  {f1_score(y_test, y_pred):.4f}")
print(f"ROC-AUC:   {roc_auc_score(y_test, y_proba):.4f}")

# 6. Feature Importances
importances = pd.Series(model.feature_importances_, index=X.columns)
print("\nFeature Importances:\n", importances.sort_values(ascending=False))

Understanding XGBoost Architecture

Core concepts explained for developers and students

Input Data

Features $X$ and ground truth labels $y$.

→

Tree 1 ($\hat{y}^{(1)}$)

Initial base prediction based on target mean.

→

Residual Errors

Compute gradients $g_i$ & Hessians $h_i$.

→

Tree $k$ ($\hat{y}^{(k)}$)

Fit next tree to minimize regularized objective.

→

Ensemble Sum

$\hat{y}_i = \sum_{k=1}^K f_k(x_i)$

Why is XGBoost so fast and accurate?

  • Gradient Boosting Framework: Builds decision trees sequentially, where each new tree aims to correct errors made by existing trees.
  • Regularized Objective: Integrates $L_1$ ($\alpha$) and $L_2$ ($\lambda$) regularization directly into the optimization loss function to prevent overfitting.
  • Second-Order Approximations: Employs Newton-Raphson Taylor expansion (1st gradients and 2nd Hessians) for swift optimization.

Hyperparameter Tuning Guide

  • Learning Rate ($\eta$): Scales tree contributions. Lower values require more trees but improve generalizability.
  • Max Depth: Limits tree height. Deeper trees capture complex feature interactions but increase risk of overfitting.
  • Subsample & Colsample: Introduces stochastic sampling per tree/split to make models robust against noise.
